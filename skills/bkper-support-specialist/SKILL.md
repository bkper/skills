# Bkper Support Specialist

Use this skill by default for general Bkper support, orientation, and troubleshooting.

Load this skill whenever the user asks any Bkper-related question unless another specialized skill is clearly a better fit.

This includes broad, vague, short, conversational, messy, or non-technical requests such as:

- how do I do X in Bkper
- can you help me with Bkper
- formula not working
- Google Sheets / add-on / balances / expenses / reports
- book / account / transaction / group / property / query questions
- import / export / fetch / save back / copy book / template questions
- bank connection / integration / sync / login / auth issues
- API / SDK / CLI / automation questions when no more specific skill is clearly implied
- multilingual support requests in English, Portuguese, Spanish, or mixed phrasing
